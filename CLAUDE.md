## File hygiene
- Keep the repo root tidy: code in `src/` (or the framework's convention), docs in `docs/`, reusable prompts in `prompts/`, throwaway scratch in `.scratch/` (git-ignored).
- No `*.bak`, `*.orig`, `*-old`, `*-copy`, `final2` files. Git is the backup: commit instead of copying.
- Never delete outright. Move unwanted files to `/srv/hub/quarantine/<date>/brown-family-kitchen/` and mention it in the report. (checkup purges quarantine after 30 days.)
- Never commit secrets, `.env`, keys, DB dumps, or logs. Add new patterns to `.gitignore`.
- Keep `.env.example` listing every required variable name with fake values.
- No global installs or system-config edits without asking. Use a project-local venv / node_modules.

## Git
- One repo per project. `main` is always deployable. Use `feat/…`, `fix/…`, `chore/…` branches for anything non-trivial.
- Commit messages: see "Project conventions" above (CookBook-NNN).
- Push at the end of every session. Never force-push `main`.
- Finish with a clean working tree, or state why not in the report.
